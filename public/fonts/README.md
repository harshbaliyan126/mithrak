# Athelas web fonts

Athelas (TypeType) is a commercial typeface, so it is not bundled here.
Buy a web licence and drop these files into this folder:

- Athelas-Regular.woff2
- Athelas-Italic.woff2
- Athelas-Bold.woff2

Until then, the site uses a locally installed Athelas (it ships with macOS)
and falls back to Iowan Old Style / Palatino / Georgia.
